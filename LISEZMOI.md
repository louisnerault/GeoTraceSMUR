# GéoTrace SMUR — appli smartphone

Coquille installable (icône + plein écran) qui affiche la web app Apps Script.

## Migration vers le compte d'exploitation
Dans index.html, remplacer la valeur de URL_WEBAPP par la nouvelle URL /exec.
L'adresse de l'appli et les icônes déjà installées sur les téléphones ne changent pas.
Si la clé change, chaque utilisateur la ressaisit une fois (ou réinstalle via le lien #cle=).
